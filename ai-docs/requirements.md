### F2. 水平气泡尺

**功能描述**：
模拟实体三合一气泡水平尺，在一个页面中同时显示水平管、垂直管、45°管，管内气泡随手机倾斜实时移动。同时显示精准刻度线。

**页面布局**：
```
┌──────────────────────────────────┐
│  ← 水平气泡尺                      │ (导航栏)
├──────────────────────────────────┤
│                                  │
│  ┌───[===●====]───┐              │ (水平气泡管 - 横向)
│  │  刻度线 cm/inch  │              │
│  └────────────────┘              │
│                                  │
│       ┌──┐                       │
│       │==│                       │
│       │==│                       │ (垂直气泡管 - 纵向)
│       │●=│                       │
│       │==│                       │
│       └──┘                       │
│                                  │
│     ╲               ╱            │
│      ╲    ●       ╱             │ (45°气泡管 - 斜向)
│       ╲─────────╱               │
│                                  │
│  当前角度: X: 2.5°  Y: -1.3°     │ (angle-display组件)
│                                  │
│  ┌────────────────────────────┐  │
│  │  [ 校准 ]   灵敏度: ●●●○○  │  │ (底部工具栏)
│  │             cm | inch       │  │
│  └────────────────────────────┘  │
└──────────────────────────────────┘
```

**核心逻辑**：

1. **传感器数据获取**：
   - 进入页面 `onLoad` 时，调用 `wx.startDeviceMotionListening({ interval: 'game' })` 启动传感器
   - 监听 `wx.onDeviceMotionChange` 获取 alpha/beta/gamma
   - 离开页面 `onUnload` 时，调用 `wx.stopDeviceMotionListening()` 停止传感器

2. **三根气泡管的数据映射**：
   - 水平管：使用 `gamma` 值（手机左右倾斜），气泡向低侧移动
   - 垂直管：使用 `beta` 值（手机前后倾斜），气泡向低侧移动
   - 45°管：使用 `(beta + gamma) / √2` 合成角度

3. **气泡管组件 (bubble-tube)**：
   - 输入属性：`direction`（'horizontal' | 'vertical' | 'diagonal'）、`angle`（当前角度值）、`maxAngle`（管的最大测量范围，默认15°）
   - 使用 Canvas 2D 绘制：管体（圆角矩形/矩形）→ 刻度线 → 气泡（圆形）
   - 气泡位置 = 管长度 × (angle / maxAngle) / 2，从中心偏移
   - 当角度接近0°（水平）时，气泡变绿色；偏离时渐变为黄色→红色

4. **刻度尺组件 (ruler-scale)**：
   - 紧贴水平气泡管显示
   - 根据设备PPI计算物理尺寸刻度间距
   - 支持 cm/inch 切换
   - 刻度线分三级：大刻度（每cm/inch，长线+数字）、中刻度（每5mm，中线）、小刻度（每1mm，短线）

5. **校准功能**：
   - 点击"校准"按钮 → 记录当前 beta/gamma 作为偏移量 → 按钮文字变为"重置校准"
   - 点击"重置校准" → 清除偏移量 → 按钮文字恢复"校准"
   - 校准后，显示的角度 = 原始角度 - 偏移量

6. **灵敏度设置**：
   - 5档灵敏度，通过调整低通滤波器α系数实现
   - 档位1(超稳定α=0.05) → 档位5(超灵敏α=0.7)
   - 默认档位3(标准α=0.2)
   - 切换后立即生效，设置保存到本地Storage

**验收标准**：
- [ ] 三根气泡管同时显示，气泡随手机倾斜实时移动
- [ ] 手机放平时三根管的气泡均在中心位置
- [ ] 刻度尺显示正确，cm/inch可切换
- [ ] 校准功能正常：校准后当前位置角度显示为0°
- [ ] 灵敏度可切换，效果可感知（稳定档气泡移动缓慢，灵敏档快速响应）
- [ ] 页面退出后传感器监听正确停止
- [ ] 角度数值显示精确到小数点后1位

### F3. 万向水平仪

**功能描述**：
显示一个360°罗盘，罗盘上有小圆点随设备倾斜实时移动，同时数字显示X/Y轴角度。提供校准、记录角度、灵敏度调节功能。

**页面布局**：
```
┌──────────────────────────────────┐
│  ← 万向水平仪                      │ (导航栏)
├──────────────────────────────────┤
│                                  │
│         ┌─────────────┐          │
│        ╱   0°          ╲         │
│      ╱  330°    30°      ╲       │
│    ╱  300°  ┼─────┼ 60°   ╲     │
│   │ 270° ───── ● ───── 90° │    │ (罗盘表盘 - compass-dial)
│    ╲  240° ┼─────┼ 120°  ╱      │ (●=小圆点随倾斜移动)
│      ╲  210°   150°    ╱        │
│        ╲   180°      ╱          │
│         └─────────────┘          │
│                                  │
│    X: -3.355°    Y: -5.566°     │ (angle-display组件)
│                                  │
│  ┌────────────────────────────┐  │
│  │  [ 校准 ]   灵敏度: ●●●○○  │  │
│  ├────────────────────────────┤  │
│  │  [ 记录角度 ]  [ 我的记录 ]  │  │
│  └────────────────────────────┘  │
└──────────────────────────────────┘
```

**核心逻辑**：

1. **罗盘组件 (compass-dial)**：
   - 输入属性：`angleX`（X轴角度）、`angleY`（Y轴角度）
   - Canvas绘制内容：
     - 外圈：360°刻度线（每10°一个大刻度带数字，每5°一个小刻度）
     - 内部：十字线（水平+垂直中心线）
     - 中心：小圆点指示器，位置由 angleX/angleY 映射
   - 小圆点位置计算：将X/Y角度归一化映射到罗盘半径范围内，限制在圆盘范围内
   - 当小圆点在中心附近（接近水平）时变绿色，偏离时变红色

2. **传感器数据映射**：
   - X轴角度（罗盘上下移动）= `beta`（手机前后倾斜）
   - Y轴角度（罗盘左右移动）= `gamma`（手机左右倾斜）
   - 数据经过低通滤波 → 灵敏度缩放 → 校准修正后传入罗盘组件

3. **校准功能**：同 F2，校准后小圆点回到中心，角度显示0°

4. **记录角度**：
   - 点击"记录角度"按钮
   - 获取当前X/Y角度值
   - 请求位置权限（如已授权则直接获取，未授权则弹窗询问）
   - 生成唯一记录ID（时间戳+4位随机数）
   - 保存记录到本地Storage（`wx.setStorageSync('angle_records', records)`）
   - Toast提示"记录成功"

5. **我的记录入口**：
   - 点击"我的记录"按钮 → 跳转到 `pages/records/records`

6. **灵敏度设置**：同 F2

**验收标准**：
- [ ] 罗盘正确显示360°刻度
- [ ] 小圆点随手机倾斜实时移动，手机放平时在中心
- [ ] X/Y角度数值精确到小数点后3位
- [ ] 校准功能正常工作
- [ ] 记录角度可保存到本地
- [ ] 灵敏度可调节
- [ ] 小圆点不会跑到罗盘范围外

**核心逻辑**：

   - 无记录时显示空状态提示："暂无测量记录，去万向水平仪记录第一个角度吧"

## 全局交互规则

### G1. 传感器生命周期管理
- **启动**：进入气泡尺/万向水平仪页面的 `onLoad` 中启动
- **暂停**：页面 `onHide`（切后台/跳转其他页面）时停止监听
- **恢复**：页面 `onShow`（回到页面）时重新启动监听
- **销毁**：页面 `onUnload` 时彻底停止并清理

### G2. 数据处理管道
```
传感器原始数据(alpha/beta/gamma)
  → 异常值过滤（丢弃NaN/Infinity）
  → 低通滤波（平滑噪声，α由灵敏度档位决定）
  → 校准修正（减去偏移量，如已校准）
  → 角度值分发给UI组件
  → Canvas重绘 / 数值更新
```

### G3. 存储键名约定
- `angle_records`: 角度记录数组 `AngleRecord[]`
- `user_settings`: 用户设置 `UserSettings`
- `calibration_data`: 校准偏移数据

### G4. 分享机制
- 使用 `onShareAppMessage` 生命周期
- 分享路径格式：`/pages/record-detail/record-detail?type=record&ax=X&ay=Y&t=TIMESTAMP&loc=LOCATION`
- 分享图片：自动截取当前页面或使用默认封面
